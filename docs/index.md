# todoapp

FastAPI backend (`backend/`) with auth and mail modules, plus an Expo frontend (`frontend/`).

## Install

```bash
cd backend
uv sync
```

## Run

```bash
cd backend
uv run uvicorn backend.main:app --reload
```
